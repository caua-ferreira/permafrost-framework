# Contributing to Permafrost Framework

Thank you for your interest in contributing! Contributions of all kinds are welcome.

## How to contribute

1. **Fork** the repository and create your branch from `main`.
2. **Install** the development dependencies:
   ```bash
   pip install -e ".[dev]"
   ```
3. **Make your changes** and add tests for any new functionality.
4. **Run the test suite** to make sure everything passes:
   ```bash
   pytest tests/ -v
   ```
5. **Open a Pull Request** with a clear description of the changes.

## Reporting issues

Please use [GitHub Issues](https://github.com/caua-ferreira/permafrost-framework/issues) to report bugs or request features.

## Code style

- Follow PEP 8.
- Keep functions small and well-documented.
- Add docstrings to public functions and classes.
